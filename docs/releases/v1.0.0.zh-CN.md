# Slide Defense Weaver v1.0.0

[English release notes](https://github.com/hujizhou35-cmd/slide-defense-weaver/releases/tag/v1.0.0) · [中文主页](../README.zh-CN.md)

**让每一页共同讲完一个故事。**

首个公开版本提供理解项目、讨论故事和PPT页序、经用户选择后逐页出稿，以及模拟提问和压力问答准备的完整流程。默认交付三个独立Word文件；纯章节页无口播，团队介绍按用户选择和规则处理。

## 检查范围

包含现有22项辅助脚本测试，以及打包一致性、确定性构建和独立文件引用检查。客户端安装与发现验证的实际版本和结果见英文Release说明。包检查和客户端发现不等于完整答辩质量验收；生成Word及渲染仍需要AI环境具备相应工具，真实用时需要排练。
